YG — ORIGINAL
=============

Сборка оригинальной игры без изменений игрового содержимого.
Исходники, сцены, скрипты и ресурсы взяты из папки: ..\yg

WINDOWS
-------
Запуск: Yg.exe
Один файл, установка не требуется.
Требования: Windows 7 / 8 / 10 / 11, 64-bit, OpenGL 2.1.
Сохранения: %APPDATA%\Godot\app_userdata\Yg\savegame.json

УПРАВЛЕНИЕ
----------
WASD / стрелки   — движение
Пробел           — прыжок
Esc              — пауза
На телефоне: виртуальный джойстик и кнопка прыжка.

СОДЕРЖИМОЕ
----------
Туториал и 5 оригинальных уровней:
1. Первый уровень
2. Второй уровень
3. Третий уровень
4. Босс
5. Обратный мир

БРАУЗЕРНАЯ ВЕРСИЯ (HTML5)
-------------------------
Запуск: run_web.bat
Скрипт поднимает локальный HTTP-сервер и открывает игру в браузере.
Открывать web/index.html напрямую нельзя — WebAssembly требует HTTP.
Папку web можно разместить на любом веб-сервере.

ВАЖНО
-----
Это именно оригинальная версия: игровые механики, уровни, меню,
баланс и поведение не менялись. Добавлены только файлы экспорта
(Windows-шаблон, README, скрипт локального веб-сервера).
